# Privacy review

This archive was assembled from selected configuration files, with a separate custom plugin
archive. It does not contain a home-directory backup.

Removed or replaced: source username/home paths, location, custom plugin author/namespace,
personal service/model aliases, hardware descriptions, fixed display assignments and HDR
calibration, monitor-bound desktop/lock-screen placements, screenshot paths and custom
screenshot upload/pipe integration, and wallpaper timestamp metadata. The installer fills
in paths and display names on the recipient's machine.

Excluded: credentials, browser/app accounts, network connection profiles, clipboard and
notification history, recently used applications, launcher usage counts, calendar state,
plugin notes/state, recordings, cache, logs, screenshots, backups, model weights, and Git
metadata. Broad system/user environment dumps and package inventories were not included.

The wallpaper's visible artwork and brand mark are preserved because the requested image
is included; metadata was removed without changing pixels. Public application IDs in window
rules and functional configuration preferences remain. This is an identifying-data review,
not a guarantee that a recognizable public theme or artwork cannot be associated with a user.

The shareable archives normalize ownership and timestamps. Installation backups are created
only on the recipient's machine and can contain their personal configuration; keep those local.
